The AppImage uses the unmodified type-2 runtime shipped in appimagetool 1.9.1.
The packaging helper pins the full tool's SHA-256, extracts its runtime prefix
and passes it explicitly with --runtime-file. The runtime version identifies
https://github.com/AppImage/type2-runtime/commit/caf24f9
Source, build scripts and dependencies:
https://github.com/AppImage/type2-runtime/tree/caf24f9
https://github.com/AppImage/appimagetool/tree/1.9.1
To extract/replace the runtime, --appimage-offset prints its byte length;
the game filesystem can be extracted separately with --appimage-extract.
