# AGENTS.md

This is a project for a puzzle game written in C++, in which you must guide all the arrows out of the maze without letting them collide with each other.

The ai-docs folder contains project information in the form of a “roadmap.” Think of it as your personal memory, so you don’t lose anything important when switching between parallel chats. Save and organize the information in a way that will make it easiest for you to find what you need later. Write down everything you consider important there without asking for permission or notifying me. This folder is tracked in Git, so it’s best to use English.

After each logically complete change, make a commit and push; write commit messages in English. Include only changes relevant to the task; preserve others’ uncommitted edits.

If the EXE build failed because the file couldn't be overwritten—since the old EXE is running—feel free to kill that process; there's no need to create a new build in a different location.
