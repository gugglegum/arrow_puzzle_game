# Документация Arrow Puzzle

[English](../en/README.md) | **Русский**

Эти руководства описывают устройство, разработку и выпуск игры. Это общая
техническая документация для разработчиков и ИИ-ассистентов.

- [Путеводитель по проекту](PROJECT_GUIDE.md): назначение, архитектура, модели,
  сборка, тесты и рабочий процесс разработки.
- [Генератор](GENERATOR.md): конструктивная генерация, инварианты, метрики
  качества и производительность.
- [Игровой цикл](RUNTIME.md): симуляция, движение, коллизии, отрисовка, меню,
  настройки и сохранения.
- [Релизы](RELEASING.md): сборка GitHub Actions, локальная подготовка, упаковка
  и проверка происхождения EXE и ZIP.
- [Общие скриншоты](../screenshots/): изображения для обоих основных README.

Пользовательское описание находится в [README.md](../../README.md) и
[README_RU.md](../../README_RU.md). В исходном репозитории правила работы
агентов находятся в `AGENTS.md`, а краткая дорожная карта и память проекта —
в `ai-docs/README.md`.

Сохраняйте одинаковые имена файлов и обновляйте обе языковые версии при
изменении технических сведений. Команды выполняются из корня репозитория,
если явно не указано другое.
